Project Overview

The goal of this project was to explore algorithmic generation of facade patterns based on solar analysis data. By creating a custom Grasshopper definition, we were able to optimize the shading coefficients while maintaining daylight access.

Key Features

  • Data-driven geometry generation
  • Automated fabrication documentation
  • Interactive visualization for client review
